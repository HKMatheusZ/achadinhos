
# 🛍️ Achadinhos

**Achadinhos** é um site de ofertas e recomendações de produtos, criado para ajudar as pessoas a encontrar bons preços e produtos interessantes por meio de links de afiliados do Mercado Livre e da Shopee.

## ✨ Funcionalidades

- 🔎 Busca de produtos por nome.
- 🏷️ Filtros por categorias.
- 🛒 Cartões de produtos com imagens, descrições e preços.
- 🔗 Links de afiliados para acessar as ofertas.
- 📱 Design responsivo para computadores e celulares.
- 🎨 Interface moderna e fácil de personalizar.

## 🚀 Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
4. Para facilitar o desenvolvimento, utilize o Visual Studio Code com a extensão Live Server.

## 🛍️ Como adicionar produtos

1. Abra o arquivo `js/products.js`.
2. Adicione um produto seguindo o padrão dos produtos existentes.
3. Informe nome, descrição, preço, categoria, imagem e link de afiliado.
4. Salve o arquivo e teste o site no navegador.

**Importante:** mantenha os nomes dos campos e o formato de dados esperados pelo arquivo `js/script.js`.

## 🔗 Programas de afiliados

O site poderá utilizar links de afiliados de plataformas como:

- [Mercado Livre](https://www.mercadolivre.com.br/)
- [Shopee](https://shopee.com.br/)

Para receber comissões, participe dos programas oficiais de afiliados e utilize seus links rastreáveis. As comissões dependem das regras de cada plataforma e das compras qualificadas.

## 🌐 Como publicar no GitHub Pages

1. Crie um repositório público chamado `achadinhos` no GitHub.
2. Envie todos os arquivos, mantendo a estrutura de pastas.
3. Entre em **Settings → Pages**.
4. Em *Build and deployment*, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Clique em **Save** e aguarde a publicação.

O endereço será semelhante a:

`https://SEU-USUARIO.github.io/achadinhos/`

Substitua `SEU-USUARIO` pelo seu nome de usuário do GitHub.

## ⚠️ Aviso sobre ofertas e afiliados

Os preços e a disponibilidade dos produtos podem mudar. Confira e atualize as informações sempre que possível.

O Achadinhos é um projeto independente e não representa oficialmente o Mercado Livre ou a Shopee. Informe aos visitantes, de forma clara, que você pode receber comissões pelas compras realizadas por meio dos links de afiliados, sem custo adicional para o comprador.
